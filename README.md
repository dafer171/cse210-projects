# CSE-210 Programing with Classes

# David Peña

## Description

This repository covers the principles of object-oriented programming (OOP), focusing on classes and their applications in software design. Through encapsulation, inheritance, and polymorphism, I have learned to develop scalable and maintainable software. By applying these techniques, I’ve enhanced my ability to handle change and reduce maintenance costs in software development.

## Objectives

Understand and articulate OOP principles.
Design software systems using classes.
Implement working software using encapsulation, inheritance, and polymorphism.

This repository contains the starter code for many different projects. They are arranged as follows:

- `sandbox` - An empty project that you can use to play around with any concepts you like.
- `csharp-prep` - Starter projects for each of the C# Prep assignments.
- `prepare` - Starter projects for each of the preparation Learning Activities.
- `prove` - Starter projects for each of the prove Developer projects.
- `final` - Starter projects for final project.
